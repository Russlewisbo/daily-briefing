Privacy policy

Last updated 24 September 2026.

Daily briefing is a personal tool used only by its author, Russell Lewis, with his own Google account. It is not offered to anyone else.

What it accesses

  • Gmail (read-only): subject lines, senders, dates, labels and short snippets of recent and starred email, to decide which messages need a follow-up.
  • Google Tasks (read-only): open tasks and their due dates.

The app cannot send, modify, label or delete email or tasks.

How the data is used and stored

  • Data is fetched on the author's own computer and used only to build his daily summary.
  • To write the summary, it is processed by Anthropic's Claude under the author's own account.
  • The summary is stored only on that computer. Nothing is sold, shared, or used for advertising.
  • The Google access token is stored on that computer with owner-only file permissions.

Google API Services User Data Policy

Daily briefing's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be withdrawn at any time at myaccount.google.com/permissions.
